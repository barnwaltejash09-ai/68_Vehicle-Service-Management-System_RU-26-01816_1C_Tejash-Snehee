# Vehicle Service Management System

## 🚀 About the Project
This project is a console-based Vehicle Service Management System built in Python 3. It is designed for a service center to efficiently manage vehicle service records using Object-Oriented Programming (OOP) concepts, Dictionaries, File Handling ( `services.txt` ), and complete CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features

* **OOP Implementation:** Uses a `ServiceRecord` class for data encapsulation, cost calculation, and displaying record details.
* **Dynamic Pricing & GST:** Automatically calculates total cost based on a predefined price list plus an 18% GST calculation (`price * 1.18`).
* **File Handling:** Automatically saves and loads records from `services.txt` ensuring data persistence.
* **CRUD Operations:** Add, View, Update status, and Delete service records.
